# ICMP Analysis

## Internet Control Message Protocol

ICMP is used for diagnostic and error reporting functions.

---

## Common ICMP Messages

### Echo Request

Sent by a host to determine availability.

### Echo Reply

Response from active host.

### Destination Unreachable

Indicates communication failure.

### Time Exceeded

Occurs when packet TTL reaches zero.

---

## Security Monitoring

Excessive ICMP traffic may indicate:

- Host Discovery
- Network Mapping
- Reconnaissance Activity
