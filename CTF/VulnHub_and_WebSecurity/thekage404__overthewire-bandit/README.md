## OverTheWire: Bandit
Bandit is a wargame hosted on OverTheWire platform that teaches linux for beginners in the field of cybersecurity or linux enthusiasts. The wargame is a comprehensive resource that gets players started with linux without hand-holding. Every level is loosely based on knowledge gained on previous levels, therefore woking through each level sequentially is encouraged.

## Official Description:
> The Bandit wargame is aimed at absolute beginners. It will teach the basics needed to be able to play other wargames.

Check How to Play and rules of the game here: https://overthewire.org/wargames/bandit/

## General Structure:
- The `bandit` directory contains all the writeups
- Every level gets its own `.md` file
- Credentials are not provided as per the rules of the game

**NOTE:** Passwords for current level is located at `/etc/bandit_pass/<level-name>` [Solving some levels don't require passwords at first, but getting them ensures easy access next time]
