# Hack The Box Security Training

This directory documents hands-on cybersecurity training completed through
authorized Hack The Box laboratories and training environments.

## Focus Areas

Training may cover:

- Network reconnaissance
- Service enumeration
- Linux security
- Windows security
- Web security
- Vulnerability analysis
- Authentication
- Privilege escalation
- Active Directory
- Security monitoring
- Incident investigation

## Documentation Approach

Each documented laboratory should focus on:

1. Objective
2. Environment
3. Initial observations
4. Enumeration
5. Investigation methodology
6. Findings
7. Evidence
8. Security implications
9. Defensive / SOC relevance
10. Lessons learned

Sensitive credentials, flags, private keys, tokens, and other authentication
material must not be published.

## Structure

- `machines/`: Individual machine reports
- `notes/`: Cross-machine technical notes
- `evidence/`: Selected supporting evidence

## Ethical Scope

All activities must be performed within authorized Hack The Box
laboratories.

The techniques documented here should only be used against systems for which
explicit authorization has been provided.
