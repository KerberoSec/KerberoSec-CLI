## 🗂️ Repository Structure

Every completed lab is self-contained:

```text
PLATFORM/
└── LAB-NAME/
    ├── README.md
    ├── Notes.md
    ├── Walkthrough.md
    ├── Screenshots/
    └── Certificate/
```

### Each lab contains

- **README.md**: Lab overview, objectives, skills, completion details, and navigation
- **Notes.md**: My personal learning notes and concepts
- **Walkthrough.md**: Step-by-step methodology with screenshots
- **Screenshots/**: Supporting visual evidence
- **Certificate/**: Proof of completion, when available
