# 🎓 Practice Platforms

> รวม platform ที่ดีที่สุดสำหรับฝึก CTF: จากเริ่มต้นจนถึงระดับ pro

---

## 🌟 Beginner-Friendly (เริ่มที่นี่)

### picoCTF ⭐
**picoctf.org** | ฟรี
- จาก Carnegie Mellon CyLab
- โจทย์ wide-range, easy-to-medium
- เหมาะกับเริ่มต้น
- มี practice + annual competition

### TryHackMe
**tryhackme.com** | Free + Premium ($10/mo)
- Guided learning paths
- "Rooms" with hints
- Beginner-friendly UI
- เน้น practical pentesting มากกว่า pure CTF

### OverTheWire
**overthewire.org** | ฟรี
- Wargame series: Bandit (Linux basics), Narnia (binary), etc.
- ใช้ SSH connection
- Old-school แต่ดีมาก

### CTFlearn
**ctflearn.com** | ฟรี
- Wide variety
- Community-driven
- Beginner section ดี

## 💪 Intermediate

### HackTheBox (HTB) ⭐
**hackthebox.com** | Free + VIP ($14/mo)
- "Machines" (boxes): full pwn lab
- Challenges (CTF-style)
- Academy: structured courses
- Active community

### Root-Me
**root-me.org** | ฟรี
- Huge library of challenges
- All categories
- ฝรั่งเศส origin (English available)

### CryptoHack ⭐
**cryptohack.org** | ฟรี
- เน้น crypto โดยเฉพาะ
- Best place to learn crypto in CTF
- Progression from basics to advanced

### Cryptopals
**cryptopals.com** | ฟรี
- Matasano crypto challenges (8 sets, 64 challenges)
- Hands-on crypto attacks
- Classic, must-do

## 🛣 Learning Paths

### Beginner (0-3 months)
1. **picoCTF** challenges
2. **OverTheWire Bandit** (Linux fundamentals)
3. **TryHackMe** Beginner Path
4. **PortSwigger Web Academy** (Apprentice level)
5. Basic Python scripting

### Intermediate (3-12 months)
1. **HackTheBox** Easy boxes
2. **CryptoHack** sets
3. **PortSwigger** Practitioner level
4. **ROP Emporium** completion
5. Join CTFtime team
6. Compete in beginner CTFs

### Advanced (1+ year)
1. **HackTheBox** Insane boxes
2. **pwn.college** advanced modules
3. **Cryptopals** all 8 sets
4. **PlaidCTF / 0CTF** participation
5. CVE research / write writeups
6. OSCP/OSWE certification (optional)

## 🎯 Tips

### "อ่าน writeups เยอะๆ"
- ctftime.org/writeups
- Search GitHub for "{ctf-name} writeup"
- Medium / Dev.to articles

### "Build a team"
- Join Discord for CTFs ที่จะแข่ง
- Reddit r/securityCTF
- Find friends from school/work

### "Take notes"
- Use Obsidian / Notion / similar
- Paste payloads, techniques, learnings
- Build personal "playbook"

### "Don't get stuck"
- 1-2 hours stuck = ลอง category อื่น
- กลับมาอ่าน writeup หลังแข่งจบ: เรียนได้เยอะ
