# Security Policy

## Responsible use
This tool is for **authorized security testing and education only**. Run it only
against systems you own or have explicit written permission to assess. Misuse may
be illegal and is solely your responsibility.

## Reporting a vulnerability in this tool
Found a security issue in the tool itself? Please report it privately rather than
opening a public issue:

- Open a [security advisory](https://github.com/JIMIT-PARIKH-01/ctf-extras-toolkit/security/advisories/new), or
- Message me on [LinkedIn](https://www.linkedin.com/in/jimit-devangkumar-parikh/).

I'll acknowledge within a few days. This project is provided "as is" under the
MIT license, with no warranty.
