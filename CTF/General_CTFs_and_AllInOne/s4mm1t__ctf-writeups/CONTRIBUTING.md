# Contributing Notes

This is a personal writeup repository, but the format is intentionally consistent so new notes are easy to add.

## Writeup Checklist

- Use `templates/writeup-template.md`.
- Explain why each step was chosen.
- Redact active platform flags when required by platform rules.
- Avoid publishing credentials, VPN files, cookies, or tokens.
- Add screenshots only when they make the reasoning clearer.
- Update the root `README.md` table and the relevant platform index.

## Naming

Use readable folder names:

```text
TryHackMe/RootMe/
HackTheBox/Blue/
PicoCTF/Some-Challenge/
```

Prefer `writeup.md` as the main file inside each challenge folder.
