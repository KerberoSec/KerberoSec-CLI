# OverTheWire: Bandit Wargame: Solutions & Cheat Sheets

Welcome to my **OverTheWire Bandit** repository. This repository contains detailed solutions, command write-ups, visual cheatsheets, and reference guides compiled while solving levels in the OverTheWire Bandit wargame.

---

## 📌 Repository Contents

The repository is structured into the following sections:

### 1. 📂 Level Walkthroughs (`/0-10 Levels`)
Step-by-step documentation and commands used to solve Bandit levels:
* **Level 0 to Level 6+ Solutions:** Detailed explanations on SSH connections, hidden file discovery, reading human-readable files, handling space-separated filenames, and filtering base64/hex data.

### 2. 📄 Text Reference & Roadmap (`/Cheat sheet .txt`)
Quick reference guides and methodologies for command line security operations:
* **A TO Z MASTER ROADMAP & CHEAT SHEET.txt:** Comprehensive overview of essential Linux commands, flags, and command-line tricks.
* **Way to find password.txt:** Logical strategies and command combinations for searching target flags and credentials within a Linux filesystem.

### 3. 🖼️ Visual Cheat Sheets & Diagrams (`/Cheat sheet .png`)
Infographics and cheat sheet screenshots for fast visual lookup:
* **GREP Command Tutorials:** Visual breakdowns of regex filtering, searching strings, and line matching.
* **OverTheWire & File Rules Cheatsheets:** Diagrams covering file permissions, file properties, and Linux CLI search methods.

* **Linux Navigation & File Manipulation:** `cd`, `ls`, `cat`, `file`, `find`, `du`
