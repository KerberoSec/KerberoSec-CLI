# Tools

## Definition

Software used by attackers to conduct malicious operations.

## Examples

- Mimikatz
- BloodHound
- Cobalt Strike
- Metasploit

## Detection Methods

- Process monitoring
- Command-line auditing
- EDR detections
- Behavioral analytics

## Advantages

- Detection significantly impacts attacker operations.

## Limitations

- Attackers may use custom tools.

## MITRE ATT&CK Relevance

Credential Access, Discovery, Lateral Movement.

## SOC Use Case

Mimikatz execution is detected through suspicious LSASS access attempts.
