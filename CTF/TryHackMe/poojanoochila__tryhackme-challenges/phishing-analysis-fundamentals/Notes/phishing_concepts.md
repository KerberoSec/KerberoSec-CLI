# Phishing Concepts

## What is Phishing?

Phishing is a social engineering attack where attackers impersonate trusted entities to steal sensitive information.

## Common Types

- Email Phishing
- Spear Phishing
- Whaling
- Smishing
- Vishing
- Clone Phishing

## Objectives

- Credential theft
- Malware delivery
- Financial fraud
- Data exfiltration
