# Port Scanning

## Purpose

Port scanning identifies open services running on a target.

---

## Information Gathered

- Open Ports
- Running Services
- Service Versions
- Attack Surface

---

## Common Scan Types

### TCP Connect Scan

Completes full TCP handshake.

### SYN Scan

Half-open scan commonly used for stealth.

### UDP Scan

Discovers UDP services.

---

## Security Impact

Port scanning often represents early-stage reconnaissance activity.
