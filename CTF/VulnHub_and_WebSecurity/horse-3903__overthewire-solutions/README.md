## About

[OverTheWire](https://overthewire.org/wargames) is a platform offering a series of progressive wargames designed to teach security concepts through practical, hands-on challenges. Each wargame focuses on a distinct skill set: from basic Linux command-line usage to advanced exploitation techniques.

## Wargames

| Wargame | Focus |
|---|---|
| **Bandit** | Linux fundamentals, file system navigation, SSH, bash scripting |
| **Behemoth** | SUID binaries, basic exploitation, privilege escalation |
| **Krypton** | Classical cryptography, ciphers, frequency analysis |
| **Leviathan** | SUID exploitation, basic reverse engineering |
| **Narnia** | Buffer overflows, memory corruption, basic pwn |
| **Natas** | Web security: SQL injection, LFI, source code review |
