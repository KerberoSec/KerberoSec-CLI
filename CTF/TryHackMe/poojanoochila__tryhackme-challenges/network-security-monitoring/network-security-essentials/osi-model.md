# OSI Model

## Layer 7: Application

Provides services directly to users and applications.

Examples:
- HTTP
- HTTPS
- DNS
- SMTP

---

## Layer 6: Presentation

Responsible for:

- Encryption
- Compression
- Formatting

---

## Layer 5: Session

Manages communication sessions between devices.

---

## Layer 4: Transport

Responsible for end-to-end communication.

Protocols:
- TCP
- UDP

---

## Layer 3: Network

Responsible for routing packets.

Protocol:
- IP

Device:
- Router

---

## Layer 2: Data Link

Handles frame delivery.

Device:
- Switch

---

## Layer 1: Physical

Transmission of bits through physical media.

Examples:
- Ethernet cable
- Fiber optic cable
