# Tools

Small helper scripts used while solving challenges.

Keep tools generic enough to reuse when possible, but mention the related challenge in the script header or README when a tool is challenge-specific.

## Suggested Format

```text
tools/
├── web/
├── crypto/
├── osint/
├── forensics/
└── README.md
```

## Notes

- Avoid committing secrets, cookies, VPN files, or platform tokens.
- Prefer short usage examples in each script.
- Keep exploit scripts educational and tied to legal CTF targets.
