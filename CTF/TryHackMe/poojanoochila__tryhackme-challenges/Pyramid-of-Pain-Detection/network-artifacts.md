# Network Artifacts

## Definition

Patterns observed in network traffic generated by malicious activity.

## Examples

- User-Agent strings
- DNS patterns
- URI paths
- Beaconing traffic

## Detection Methods

- Zeek
- Suricata
- Wireshark
- IDS systems

## Advantages

- Difficult to alter consistently.

## Limitations

- Attackers may encrypt traffic.

## MITRE ATT&CK Relevance

Command and Control techniques.

## SOC Use Case

An analyst identifies periodic beaconing every 60 seconds to a remote server.
