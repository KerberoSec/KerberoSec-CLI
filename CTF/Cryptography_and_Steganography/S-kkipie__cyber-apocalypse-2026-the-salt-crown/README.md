# Cyber Apocalypse CTF 2026: The Salt Crown

Writeups (solucionarios) for challenges solved during **HackTheBox Cyber Apocalypse CTF 2026: The Salt Crown**.

Each folder holds a `WRITEUP.md` plus the solver scripts / source used to reach the flag. Challenge distributions, binaries, packet captures, disk images and dependency trees (`node_modules`, `venv`, build artifacts) are intentionally omitted to keep the repo lean: the writeups describe how to reproduce.
