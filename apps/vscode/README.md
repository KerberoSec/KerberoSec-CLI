# KerberoSec VS Code Extension

KerberoSec is an autonomous AI coding assistant integrated directly into Visual Studio Code. It provides step-by-step agentic planning, multi-file edits, terminal execution, and browser interaction with human-in-the-loop permission controls.

## Development

```bash
# Install dependencies
bun run install:all

# Generate protocol buffer definitions
bun run protos

# Build webview UI
bun run build:webview

# Run unit tests
bun run test:unit
```

For full setup and contribution details, refer to [CONTRIBUTING.md](../../CONTRIBUTING.md) and [README.marketplace.md](./README.marketplace.md).
