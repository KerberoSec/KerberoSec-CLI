# Defensive Security Intro Lab

> **Platform:** TryHackMe 
> **Difficulty:** Easy  
> **Category:** SOC / Blue Team / Cybersecurity Fundamentals

## Overview

This repository documents my learning experience from the Defensive Security Intro room on TryHackMe. The room provides an introduction to defensive cybersecurity by explaining the responsibilities of Blue Teams, the role of Security Operations Centers (SOC), Digital Forensics and Incident Response (DFIR), Malware Analysis, Threat Intelligence, and Security Information and Event Management (SIEM).

It serves as a foundational room for understanding how organizations detect, investigate, and respond to cyber threats.

---

## Objectives

- Understand the role of Defensive Security.
- Learn the responsibilities of the Blue Team.
- Explore the functions of a Security Operations Center (SOC).
- Understand the purpose of Digital Forensics and Incident Response (DFIR).
- Learn the basics of Malware Analysis.
- Understand how SIEM supports threat detection.
- Gain insight into the defensive security workflow.

---

## Learning Methodology

During this room, I approached each topic from the perspective of a SOC analyst responsible for protecting an organization's infrastructure.

My learning process included:

- Understanding the responsibilities of Blue Team operations.
- Exploring how SOC analysts monitor and respond to security incidents.
- Learning the role of Threat Intelligence in identifying emerging threats.
- Understanding how DFIR helps investigate and recover from security incidents.
- Exploring how malware analysis assists in identifying malicious software.
- Learning how SIEM platforms collect, correlate, and analyze security events.
- Completing a practical exercise demonstrating how defensive security detects and blocks malicious activity.

This approach helped me understand how multiple security disciplines work together to defend an organization's assets.

## Key Takeaways

This room provided a high-level understanding of the major domains within defensive cybersecurity. One of the biggest lessons was recognizing that effective cyber defense depends on collaboration between multiple teams and technologies. SOC analysts, DFIR teams, threat intelligence analysts, malware analysts, and SIEM platforms all contribute to detecting, investigating, and responding to cyber threats.

It also reinforced that defensive security is a continuous process involving monitoring, analysis, investigation, and improvement rather than reacting only after an incident occurs.

The **Defensive Security Intro** room established a strong foundation in Blue Team operations and modern security practices. It introduced the core disciplines involved in defending enterprise environments and demonstrated how SOC operations, DFIR, Threat Intelligence, Malware Analysis, and SIEM work together to improve an organization's overall security posture.

This room serves as an excellent starting point for anyone pursuing a career in SOC Analysis, Incident Response, Threat Hunting, or Blue Team cybersecurity.
