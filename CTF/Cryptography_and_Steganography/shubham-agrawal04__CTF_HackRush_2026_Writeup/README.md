## Overview

This repository contains writeups for challenges solved during **HackRush CTF 2026 @ IITGN**.

The CTF followed a **Jeopardy-style format** with problems across multiple domains including:
- Cryptography  
- Web Exploitation  
- Forensics  
- Steganography  
- Miscellaneous  

Each challenge is documented in a **separate Markdown file**, detailing:
- Problem understanding  
- Step-by-step approach  
- Tools used  
- Failed attempts (where relevant)  
- Key insights and learnings
