KerberoSecPass is a low-cost monthly subscription — **$9.99/month** — that offers **2-5x the usage** on popular open coding models compared to standard API rate.

It's completely optional. You don't need KerberoSecPass to use KerberoSec, and you can always use any other provider alongside it.

## How it works

KerberoSecPass is a separate provider in KerberoSec. After subscribing, select **KerberoSecPass** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **KerberoSecPass**, and sign in.

  <img src="/assets/kerberosecpass/kerberosecpass-ide-extension.png" alt="KerberoSec IDE extension settings with KerberoSecPass selected as the API Provider" />

- **CLI**: Go to `/settings` and select **KerberoSecPass** as your provider.

## Why KerberoSecPass

Open models have gotten really good. They now reach performance close to proprietary models for coding tasks, and because many providers can serve them competitively, they're usually far cheaper.

However, getting reliable access can be difficult. Providers vary in quality and availability, and standard rate limits can throttle heavy agentic workflows that read files, run commands, and iterate across many turns.

KerberoSecPass solves this by:

- Curating a select group of open models tested and benchmarked for coding agent use
- Offering **2-5x the usage** on popular open coding models compared to standard API rate, so you can run long, complex agent tasks without interruption
- Providing stable access through KerberoSec's infrastructure

<Note>
KerberoSecPass is a separate provider from KerberoSec (usage-billing). You can use both independently — subscribe to KerberoSecPass for 2-5x the usage on popular open coding models compared to standard API rate, or use KerberoSec (usage-billing) for pay-as-you-go access.
</Note>

## Using KerberoSecPass outside of KerberoSec

You can use KerberoSecPass models from your own scripts, apps, or automation through the KerberoSec API. The API uses the same OpenAI-compatible Chat Completions format as the rest of KerberoSec's API.

To get started, create an API key from **Settings > API Keys** in [app.kerberosec.bot](https://app.kerberosec.bot). For the complete walkthrough, see the [KerberoSec API Getting Started guide](/api/getting-started).

Use the full KerberoSecPass model slug in the `model` field:

```bash
export KERBEROSEC_API_KEY="your_api_key_here"

curl -X POST https://api.kerberosec.bot/api/v1/chat/completions \
  -H "Authorization: Bearer $KERBEROSEC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kerberosec-pass/qwen3.7-max",
    "messages": [
      {"role": "user", "content": "Write a TypeScript function that validates an email address."}
    ],
    "stream": false
  }'
```

## Usage

KerberoSecPass measures usage against three limits:

- **5-hour rolling window** — your usage within rolling 5-hour period
- **Weekly** — your usage over the calendar week
- **Monthly** — your usage over the calendar month

To check your current usage, visit your [KerberoSec dashboard](https://app.kerberosec.bot/dashboard/subscription?personal=true).
