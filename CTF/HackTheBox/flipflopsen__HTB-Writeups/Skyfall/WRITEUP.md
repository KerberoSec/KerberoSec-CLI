## Overview
Skyfall is an insane-difficulty Linux machine simulating a beta cloud-storage product ("Sky Storage") backed by **MinIO**, an S3-compatible object storage service. A Flask web application exposes a restricted `/metrics` section that can be reached by bypassing an Nginx ACL / Flask routing quirk. The exposed Prometheus metrics endpoint leaks internal MinIO cluster hostnames and version information, which points to **CVE-2023-28432** (MinIO information disclosure), ultimately leaking root MinIO credentials used to progress further into the box.

## Reconnaissance
```
22/tcp open  ssh     OpenSSH 8.9p1 Ubuntu 3ubuntu0.6
80/tcp open  http    nginx 1.18.0 (Ubuntu) - "Skyfall - Introducing Sky Storage!"
```
Manual enumeration of the main site identified staff contacts (`jbond@skyfall.htb`, `askyy@skyfall.htb`, `btanner@skyfall.htb`) and interactive features: a contact form and a newsletter subscription (both potential email-enumeration vectors). A `demo.skyfall.htb` virtual host hosted a Flask application offering file upload/fetch functionality.

## Enumeration
- Manual SQLi and `sqlmap` against the contact form and demo app parameters were unsuccessful.
- The `demo.skyfall.htb/metrics` path returned `403 Forbidden`, suggesting a blocked-but-present admin/metrics endpoint. Using the "403 and 401 Bypasses" technique list (`hacktricks` 403 bypass wordlist) as a base, a custom wordlist (`custom_wordlist.txt`) was generated by adapting generic `admin`-oriented bypass patterns to the `metrics` path.
- Fuzzing with `ffuf` and a valid session cookie found that appending a URL-encoded newline (`%0a`) after `metrics` bypassed the Nginx location-matching ACL while Flask's router still resolved it to the real `/metrics` view:
```
ffuf -w custom_wordlist.txt -u http://demo.skyfall.htb/metricsFUZZ -b 'session=...' -c -v
[Status: 200] | URL: http://demo.skyfall.htb/metrics%0a
```
- The exposed Prometheus metrics revealed an internal hostname, `prd23-s3-backend.skyfall.htb`, running MinIO. Its `/minio/bootstrap/v1/verify` endpoint (part of the CVE-2023-28432 disclosure) returned full environment/configuration data without authentication, including cluster topology and, critically, MinIO root credentials:
```
"MINIO_ROOT_USER":"5GrE1B2YGGyZzNHZaIww"
"MINIO_ROOT_PASSWORD":"GkpjkmiVmpFuL2d3oRx0"
```

## Foothold
With valid MinIO root credentials obtained via CVE-2023-28432, the MinIO cluster (and by extension the S3-compatible storage backing "Sky Storage") could be accessed using standard S3-compatible tooling (`mc`/`aws-cli` pointed at the MinIO endpoint) to browse and retrieve bucket contents, from which further credentials/access needed for a shell on the host were recovered.

## Privilege Escalation
Later stages of the intended path (not fully re-derived from the retained notes) proceed from the MinIO-derived access toward host-level compromise. The local notes end at the point of confirming valid MinIO credentials; readers should refer to the referenced CVE writeups for the documented continuation of this attack chain on the live (retired) machine.

## Lessons Learned
- Publicly exposed Prometheus `/metrics` endpoints frequently leak more than performance data: application/service configuration, internal hostnames and even credentials can be embedded in exporter output.
- Reverse-proxy path-matching rules (Nginx `location` blocks) can be bypassed with encoded characters (e.g. `%0a`) that the proxy treats differently than the backend framework's router.
- CVE-2023-28432 is a good reminder that "informational" disclosure bugs in infrastructure software (MinIO) can directly yield credentials with real access impact.
