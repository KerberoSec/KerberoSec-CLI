# TCP/IP Model

## Application Layer

Combines OSI Layers 5, 6, and 7.

Examples:
- HTTP
- HTTPS
- DNS
- SMTP

---

## Transport Layer

Protocols:

- TCP
- UDP

Functions:

- Segmentation
- Reliability
- Flow Control

---

## Internet Layer

Responsible for routing.

Protocols:

- IPv4
- IPv6
- ICMP

---

## Network Access Layer

Handles physical transmission.

Examples:

- Ethernet
- Wi-Fi
