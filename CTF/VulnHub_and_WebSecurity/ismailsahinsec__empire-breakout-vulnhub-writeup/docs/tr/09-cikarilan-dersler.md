# 09: Çıkarılan Dersler

## Skills Demonstrated

- Hedef keşfi ve servis korelasyonu
- Web kaynak kodu inceleme
- SMB enumeration mantığı
- Credential bağlam doğrulaması
- Savunmacı log kaynaklarıyla düşünme

## Yaygın Hatalar

- Varsayılan sayfayı boş sanıp kaynak kodu incelememek.
- Credential adayını tek serviste başarısız oldu diye tamamen elemek.
- Kanıt olmayan root adımlarını write-up’a eklemek.

## Sınırlamalar

Bu repo yalnızca mevcut yerel dosyalarla doğrulanan bilgileri içerir. Root aşaması kanıtlanmadı.

## Gelecek İyileştirmeler

Ham nmap ve dizin keşfi çıktılarının temizlenmiş kopyaları eklenebilir. User/root proof elde edilirse ayrı kanıtla belgelenmelidir.
