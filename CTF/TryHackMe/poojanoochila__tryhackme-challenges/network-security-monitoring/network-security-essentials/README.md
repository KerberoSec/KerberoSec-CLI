# Network Security Essentials

## Overview

This repository contains my notes and learning outcomes from the TryHackMe Network Security Essentials room.

The room introduces the fundamental concepts of networking and security that form the foundation of cybersecurity operations, SOC analysis, penetration testing, and incident response.

---

## Skills Practiced

- Networking Fundamentals
- OSI Model
- TCP/IP Model
- Common Network Protocols
- Network Devices
- Ports and Services
- Secure Communication Concepts
- Security Monitoring Basics

---

## Learning Objectives

- Understand how networks communicate
- Learn the OSI and TCP/IP models
- Identify common protocols and their purposes
- Understand network infrastructure components
- Learn the role of ports and services
- Explore security mechanisms used in modern networks

## Why This Matters

Understanding networking fundamentals is critical for:

- SOC Analysts
- Incident Responders
- Threat Hunters
- Security Engineers
- Penetration Testers

Most cyber attacks generate network activity, making network knowledge one of the most important cybersecurity skills.
