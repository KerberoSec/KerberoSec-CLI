# Pyramid of Pain Detection Lab

## Overview

This repository documents my study of the Pyramid of Pain framework, a threat intelligence model developed by David Bianco. The model helps defenders understand which indicators cause the greatest operational impact on adversaries when detected and blocked.

## Pyramid Levels

| Level | Difficulty for Attacker |
|---------|----------------------|
| Hash Values | Trivial |
| IP Addresses | Easy |
| Domain Names | Simple |
| Host Artifacts | Annoying |
| Network Artifacts | Annoying |
| Tools | Challenging |
| TTPs | Tough |

## Objectives

- Understand different types of Indicators of Compromise (IOCs)
- Learn detection strategies for each indicator
- Map indicators to real-world attacks
- Improve threat hunting and SOC investigation skills
