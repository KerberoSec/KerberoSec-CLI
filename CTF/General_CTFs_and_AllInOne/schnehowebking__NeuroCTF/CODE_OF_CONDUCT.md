# Code of Conduct

## Our Standard

This project aims to be welcoming, constructive, and respectful.

Examples of expected behavior:
- being respectful in discussion and review
- giving actionable, technical feedback
- assuming good intent
- helping new contributors onboard

Examples of unacceptable behavior:
- harassment or personal attacks
- discriminatory language
- hostile or dismissive review behavior
- intentionally disruptive conduct

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors whose behavior harms the project environment.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers.
