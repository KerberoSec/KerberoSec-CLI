# Network Devices

## Router

Routes traffic between networks.

---

## Switch

Connects devices within a local network.

---

## Firewall

Filters and controls network traffic based on security rules.

---

## Access Point

Provides wireless connectivity to devices.

---

## IDS/IPS

### IDS

Intrusion Detection System

Monitors and alerts on suspicious activity.

### IPS

Intrusion Prevention System

Detects and blocks malicious traffic.
