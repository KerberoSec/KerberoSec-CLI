## Notes

**† Local solves.** Two challenges were solved end-to-end locally against the real
binaries/logic, but the *live remote flag* was not captured (server unavailable, or the
key is randomized per instance so the local flag differs from the scored one):

- **Blinky**: the full exploit works; the server derives a fresh key per run, so the
  flag shown is from a local instance.
- **BabyCOM**: the intended SYSTEM-service exploit is validated locally against the real
  binaries; the flag shown is the local placeholder the author ships (it literally spells
  out the intended technique), not a scored remote flag.

Every other writeup corresponds to a flag captured from the live competition instance.
(mafuyuuuuu, once a local-only chain, is now a confirmed **remote** solve.)
