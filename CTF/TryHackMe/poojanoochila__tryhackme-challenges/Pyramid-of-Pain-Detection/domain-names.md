# Domain Names Lab

## Definition

Human-readable names used to access resources on the Internet.

## Examples

- malicious-login.com
- fake-office365.net

## Detection Methods

- DNS monitoring
- Threat intelligence
- Proxy logs
- Secure Web Gateways

## Advantages

- Easier to remember than IP addresses
- Often used in phishing campaigns

## Limitations

- Attackers can register new domains quickly.

## MITRE ATT&CK Relevance

Phishing and Command & Control operations.

## SOC Use Case

A phishing email directs users to a suspicious domain that mimics Microsoft 365.
