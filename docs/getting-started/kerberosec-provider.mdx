KerberoSec (usage-billing) is the simplest way to get started with pay-as-you-go model access in KerberoSec.

Instead of managing separate API keys across multiple vendors, you sign in once, add **KerberoSec credits**, and select from available models directly in KerberoSec.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [KerberoSecPass](/getting-started/kerberosecpass) instead. KerberoSecPass is a separate provider in KerberoSec.

## Why use KerberoSec (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by KerberoSec
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add KerberoSec credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

KerberoSec (usage-billing) is the pay-as-you-go provider in KerberoSec. Add KerberoSec credits, then select **KerberoSec** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **KerberoSec**, and sign in.
- **CLI**: Go to `/settings` and select **KerberoSec** as your provider.

## Credits and usage

- Add **KerberoSec credits** from your [KerberoSec dashboard](https://app.kerberosec.bot/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through KerberoSec (usage-billing)
- View usage in KerberoSec Settings → **View Usage**
- Switch organizations in KerberoSec Settings → **Switch Organization**
