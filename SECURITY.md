# Security Policy

## Supported Versions

We actively patch only the most recent minor release of KerberoSec. Older versions receive fixes at our discretion.

## Reporting a Vulnerability

We appreciate your efforts to responsibly disclose your findings and will make every effort to acknowledge your contributions.

To report a security issue, please open a private security advisory on the GitHub repository at [KerberoSec-CLI Security Advisories](https://github.com/KerberoSec/KerberoSec-CLI/security/advisories/new).

When reporting, please include:

- A short summary of the issue
- Steps to reproduce or a proof of concept
- Any logs, stack traces, or screenshots that might help us understand the problem

Please keep the details private until a resolution has been reached.

Thank you for helping us keep KerberoSec users safe.
