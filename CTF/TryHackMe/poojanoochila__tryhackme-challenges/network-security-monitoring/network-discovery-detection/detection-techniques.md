# Detection Techniques

## Indicators of Scanning Activity

### High Volume Connection Attempts

Large numbers of connection requests in a short period.

### Sequential Port Access

Attempts against multiple ports on the same host.

### Multiple Host Probing

Scanning multiple systems across a network.

---

## Detection Sources

- Firewall Logs
- IDS Alerts
- IPS Alerts
- Network Traffic Logs
- SIEM Correlation

---

## SOC Analyst Actions

1. Identify source IP
2. Determine scan scope
3. Review targeted assets
4. Assess risk level
5. Escalate if necessary
