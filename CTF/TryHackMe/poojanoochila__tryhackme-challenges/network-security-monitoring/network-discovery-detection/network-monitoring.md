# Network Monitoring

## Purpose

Continuous observation of network traffic for security events.

---

## Benefits

- Threat Detection
- Incident Response
- Asset Visibility
- Performance Monitoring

---

## Monitoring Sources

### Firewall

Provides network access logs.

### IDS

Detects suspicious behavior.

### IPS

Detects and blocks threats.

### Packet Captures

Provides detailed traffic visibility.

---

## Analyst Focus Areas

- Reconnaissance Activity
- Unauthorized Access Attempts
- Malware Communication
- Suspicious Network Connections
