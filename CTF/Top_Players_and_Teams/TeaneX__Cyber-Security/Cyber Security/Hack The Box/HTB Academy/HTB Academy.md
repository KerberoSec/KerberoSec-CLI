## 🎯 Introduction

**HTB Academy** is the comprehensive educational platform from **Hack The Box**, designed to provide structured cybersecurity training for individuals at all skill levels. Unlike the main HTB platform which focuses on penetration testing practice through challenges, Academy offers curated learning paths with theoretical foundations and practical applications.

### **Key Differentiators**
- **Structured curriculum** vs. random challenges
- **Theory + Practice** combined approach
- **Career-focused** learning paths
- **Enterprise-grade** training solutions

## 🏆 Certifications

### **HTB Certified Penetration Testing Specialist (CPTS)**
- **Duration**: 30 days exam window
- **Format**: Practical penetration test
- **Scope**: Network, web app, and AD attacks
- **Difficulty**: Intermediate to Advanced

### **HTB Certified Bug Bounty Hunter (CBBH)**
- **Focus**: Web application security
- **Coverage**: OWASP Top 10 vulnerabilities
- **Methodology**: Bug bounty hunting approach

### **HTB Certified Defensive Security Analyst (CDSA)**
- **Focus**: Blue team skills
- **Coverage**: Monitoring, analysis, response
- **Tools**: SIEM, EDR, forensic tools

## 🚀 Getting Started Guide

### **Step 1: Account Setup**
1. Visit [academy.hackthebox.com](https://academy.hackthebox.com)
2. Create account or use existing HTB credentials
3. Complete profile and skill assessment

### **Step 2: Choose Your Path**
- **Complete Beginners**: Start with "Starting Point" and "Fundamentals"
- **IT Professionals**: Jump to role-specific paths
- **Experienced Hackers**: Focus on certification tracks

### **Step 3: Learning Strategy**
1. **Follow structured paths** rather than random modules
2. **Take thorough notes**: the platform allows annotation
3. **Practice consistently**: use lab time effectively
4. **Engage with community**: ask questions in discussions
5. **Apply knowledge** on main HTB platform

### **Step 4: Certification Preparation**
1. Complete all required modules for your chosen certification
2. Practice on similar machines on main HTB
3. Join study groups and practice teams
4. Schedule exam when consistently scoring high on practice labs
