# HTB Academy: Cracking into Hack the Box Path

## 🎯 Path Overview
- **Difficulty**: Easy
- **Sections**: 42
- **Time Commitment**: 2 days
- **Cubes Required**: 30
- **Target Audience**: Beginners in technical information security

---

## 📚 Path Description

### **Objective**
This path provides the foundational knowledge required to:
- Understand technical information security roles
- Navigate Hack The Box platforms effectively
- Progress through Starting Point and easy-rated machines
- Solve "live" machines independently

### **Key Focus Areas**
- Specialized tools and terminology
- Core technical concepts
- Practical penetration testing methodology
- HTB platform navigation

---

## 🗺️ Path Structure

### **Module 1: Foundations & Prerequisites**
- Introduction to information security concepts
- Essential terminology and tools
- Understanding different security roles

### **Module 2: HTB Platform Navigation**
- Main platform vs. Academy differences
- Starting Point machine progression
- Retired vs. live machine concepts
- Community and resource utilization

### **Module 3: Technical Fundamentals**
- Basic networking concepts
- Common vulnerability types
- Essential Linux/Windows commands
- Tool introduction and usage

### **Module 4: Methodology & Organization**
- Penetration testing workflow
- Note-taking and documentation
- Staying organized during assessments
- Common beginner pitfalls to avoid

### **Module 5: Penetration Testing Distributions**
- Overview of security distributions (Kali, Parrot, etc.)
- Environment setup and configuration
- Essential tool categories and purposes

---

### **Upon Completion, You Will Be Able To:**
- ✅ Navigate HTB platforms confidently
