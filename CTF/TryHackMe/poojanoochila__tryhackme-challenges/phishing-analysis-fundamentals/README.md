# Phishing Analysis Fundamentals

## Overview

This repository contains my notes, analysis exercises, and findings from completing the Phishing Analysis Fundamentals room on TryHackMe.

The room focuses on identifying phishing emails, analyzing email headers, detecting malicious indicators, and understanding common phishing techniques used by attackers.

---

## Skills Learned

- Email header analysis
- Identifying phishing indicators
- Detecting spoofed email addresses
- Understanding social engineering tactics
- IOC (Indicator of Compromise) extraction
- Basic threat investigation techniques
- Email authentication concepts (SPF, DKIM, DMARC)

---

## Key Takeaways

- Never trust sender names alone.
- Always inspect email headers.
- Verify domains before clicking links.
- Check SPF, DKIM, and DMARC results.
- Look for urgency and social engineering tactics.
