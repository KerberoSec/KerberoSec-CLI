# ARP Discovery

## Address Resolution Protocol

ARP maps IP addresses to MAC addresses on local networks.

---

## ARP Process

1. Broadcast ARP Request
2. Device Responds with ARP Reply
3. MAC Address Stored in ARP Cache

---

## Example

Who has 192.168.1.10?

Tell 192.168.1.5

---

## Security Relevance

ARP traffic can reveal:

- Active hosts
- Network topology
- Potential spoofing attacks
