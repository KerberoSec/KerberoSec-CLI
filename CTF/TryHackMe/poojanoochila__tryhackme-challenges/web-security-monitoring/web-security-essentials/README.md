# Web Security Essentials

## Overview

This repository contains my notes and learning outcomes from the TryHackMe Web Security Essentials room.

The room introduces core web technologies, HTTP communication, authentication mechanisms, session management, and common web application security risks.

---

## Skills Practiced

- Web Security Fundamentals
- HTTP & HTTPS Analysis
- Authentication Concepts
- Session Management
- Cookie Security
- Web Application Security
- Security Best Practices
- Threat Identification

---

## Learning Objectives

- Understand how web applications function
- Learn HTTP request and response structure
- Explore HTTPS and TLS protection
- Understand authentication and authorization
- Learn common web security risks
- Identify defensive security controls

---

## Topics Covered

- Web Architecture
- HTTP Methods
- HTTPS & TLS
- Cookies
- Sessions
- Authentication
- Authorization
- Web Security Controls

---

## Why This Matters

Web applications are one of the most frequently targeted attack surfaces.

Understanding web security is essential for:

- SOC Analysts
- Security Analysts
- Incident Responders
- Penetration Testers
- Application Security Engineers

---

## Learning Outcome

This room strengthened my understanding of how web applications operate and how security mechanisms protect users and systems from common threats.
