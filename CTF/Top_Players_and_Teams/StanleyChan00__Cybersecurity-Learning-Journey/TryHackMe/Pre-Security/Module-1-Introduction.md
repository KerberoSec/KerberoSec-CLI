# TryHackMe Pre Security: Module 1: Introduction to Cybersecurity 

## Offensive Security introduction
This is ethical hacking in the sense of attempting to find weaknesses in a system before real hackers do.

This lesson uses an example of finding hidden pages within a bank's wesbite: which then allows for unauthroized administrative access. 

-Using the `dirb` command on the terminal allows for a search of hidden files, pages, or directories.

In this lab's case, a URL for the bank's transfer page came up. You can then, "attack" the page by going to the URL. Then you are now free to transfer money from account to account.

I have found that this is what as knowns as a "forced browsing attack" which is possible on poorly made systems. 

## Defensive Security Introduction
This is essentially the main process of defending systems. Rather than attempting to poke holes in a system to find weaknesses like offensive security, defensive security monitors and defends against attacks or prevents them from happening in the first place.

The lab in this lesson has us acting as an SOC analyst.

The dashbord an IP address suspected of using a Web Discovery Attack, which is similar to the last lab's attack of attempting to access hidden URLs that provide administrative access. 

We detected and idenfitfied the threat as malicious. Then stopped it by blocking the IP address via the firewall.

## Careers in Cyber

#### Security Analysis
This is a broad role in regards to defensive security. 

However, generally speaking, security analysts identify potential securiity incidents within a system and then deal with them appropriately. 

This is currently the career path I'm most interested in as it feels akin to defending a war zone on the front lines. You are defending a system head on and dealing with them in a highly dynamic and fast changing environemnt. 
#### Security Engineering
Security engineers are the personnel that create and maintain the systems that protect an organisation's network and devices. 

They are the ones that provide the structure from the ground up, or the ones that maintain and strengthen it. 

#### Penetration Testing
These are the ethical hackers that look for weaknesses in a system and attempt to safely break into it.

This then allows the organization to patch those weaknesses before a malicious actor can get to it first.

This is probably my 2nd most interested career path after security analysis.
