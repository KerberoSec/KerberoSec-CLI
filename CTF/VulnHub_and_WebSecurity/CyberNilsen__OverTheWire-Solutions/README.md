  # OverTheWire Solutions 🧠🔐

  Welcome to my **OverTheWire Solutions** repository!  
  This repo contains my personal write-ups, scripts, and notes for various **OverTheWire wargames** such as **Bandit, Narnia, Leviathan, Krypton**, and more as I progress.

  Each directory corresponds to a different wargame and includes my step-by-step solutions, command breakdowns, and reasoning for each level.

  ## 🕹️ About OverTheWire

  [OverTheWire](https://overthewire.org/wargames/) provides a collection of security wargames designed to teach and improve your knowledge of:
  - Linux fundamentals  
  - Bash scripting  
  - Network protocols  
  - Privilege escalation  
  - Exploit development  
  - Cryptography  
  - Reverse engineering  

  These challenges are ideal for anyone looking to sharpen their cybersecurity and ethical hacking skills.

## ⚙️ How to Use

1. Visit the [OverTheWire website](https://overthewire.org/wargames/).
2. Pick the same wargame and level as in this repo.
3. Read through the solution to understand **how** and **why** it works.
4. Try solving it yourself before peeking at the answer!

## 🧾 Contributing

Contributions are welcome! If you'd like to contribute:
1. Fork the repository.
2. Add or improve solutions in a clearly named directory (e.g., `Bandit/X-X/README.md`).
3. Include clear explanations and the commands used.
4. Open a pull request describing your changes.

Please **do not** include spoilers in filenames or top-level README text: keep level names generic and put full details only inside the level files.
