# Network Discovery and Detection

## Overview

This repository contains my notes and learning outcomes from the TryHackMe Network Discovery and Detection room.

The room focuses on how systems are discovered on a network, how network reconnaissance works, and how defenders can detect suspicious scanning and enumeration activities.

---

- Network Discovery
- Host Enumeration
- ICMP Analysis
- Port Scanning Concepts
- Network Reconnaissance
- Detection Engineering
- Packet Analysis
- SOC Monitoring

---

## Learning Objectives

- Understand network discovery techniques
- Learn how attackers identify active hosts
- Analyze scanning activity
- Understand detection opportunities
- Explore defensive monitoring techniques
