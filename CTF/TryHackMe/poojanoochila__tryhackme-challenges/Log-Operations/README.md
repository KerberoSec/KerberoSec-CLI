# Log Operations 

> **Platform:** TryHackMe  
> **Difficulty:** Easy  
> **Category:** SOC / Blue Team / Logging

## Overview

This repository documents my learning experience from the **Log Operations** room on TryHackMe. The room focuses on the importance of logging in security operations, covering log planning, configuration, storage, accessibility, compliance requirements, and common mistakes that affect monitoring and incident response.

Instead of analysing logs directly, this room emphasizes how organizations should design and manage logging strategies to ensure logs remain useful for security monitoring, troubleshooting, compliance, and forensic investigations.

---

## Objectives

- Understand the different purposes of logging.
- Learn how to plan an effective logging strategy.
- Explore logging requirements for security and operations.
- Understand log retention and accessibility.
- Recognize common logging challenges.
- Identify best practices for log management.

---

## Learning Methodology

During this room, I approached each task from the perspective of a SOC analyst responsible for designing and maintaining a logging infrastructure.

My learning process included:

- Understanding why organizations collect different types of logs.
- Exploring how logging supports both operational and security objectives.
- Learning how compliance requirements influence logging policies.
- Studying the trade-offs between logging volume, storage, and performance.
- Understanding the importance of log retention, accessibility, and centralized collection.
- Identifying common mistakes that reduce log visibility and investigation effectiveness.

This room reinforced that effective logging is not simply collecting data: it requires careful planning to ensure logs remain useful throughout the incident response lifecycle.

## Key Takeaways

One of the biggest lessons from this room was that **effective logging starts with proper planning**. Collecting excessive logs can increase storage costs and reduce system performance, while insufficient logging creates visibility gaps that make investigations more difficult.

I also learned that successful logging strategies balance operational requirements, security needs, and compliance obligations. Well-designed logging enables faster detection, efficient investigations, reliable auditing, and stronger overall security operations.
