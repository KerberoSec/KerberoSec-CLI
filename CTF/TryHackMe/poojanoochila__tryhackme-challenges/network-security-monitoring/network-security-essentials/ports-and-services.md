# Ports and Services

## What is a Port?

A port identifies a specific service running on a device.

Examples:

- Port 80 → HTTP
- Port 443 → HTTPS
- Port 22 → SSH
- Port 53 → DNS

---

## Well-Known Ports

Range:

0: 1023

Commonly used by standard services.

---

## Registered Ports

Range:

1024: 49151

Used by applications and vendors.

---

## Dynamic Ports

Range:

49152: 65535

Temporary ports used by clients.
