# Factoring

## Flag
```
crypto{19704762736204164635843}
```

## Solution

Se factoriza `N` usando [FactorDB](http://factordb.com), una base de datos online de factorizaciones conocidas. Se obtienen los dos factores primos y el menor de ellos es la flag.

- Factores: `19704762736204164635843` y `25889363174021185185929`
- Flag: el primo más pequeño → `19704762736204164635843`
