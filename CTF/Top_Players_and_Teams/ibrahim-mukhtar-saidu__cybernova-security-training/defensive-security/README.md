# Defensive Security Training

This directory documents practical defensive-security training and exercises
that are separate from the platform-specific CTF collections.

## Focus Areas

Training may include:

- Security monitoring
- Log analysis
- Detection engineering
- Incident response
- Threat hunting
- SIEM workflows
- Alert triage
- Network monitoring
- Endpoint security
- Threat intelligence
- MITRE ATT&CK analysis

## Documentation Approach

Each exercise should document:

1. Objective
2. Environment
3. Data sources
4. Detection or investigation methodology
5. Observed evidence
6. Findings
7. Security impact
8. Detection opportunities
9. Response or mitigation considerations
10. Lessons learned

## Structure

- `labs/`: Individual defensive-security exercises
- `notes/`: Cross-lab defensive-security notes
- `evidence/`: Supporting evidence

## Ethical Scope

All exercises must use authorized environments, synthetic datasets,
or systems for which explicit permission has been provided.
