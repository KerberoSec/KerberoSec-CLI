# Inside a Computer System

Notes from TryHackMe's "Inside a Computer System" room: covers CPU, memory, OS fundamentals, and how these relate to security concepts like exploitation and forensics.

## Key concepts

**CPU/architecture notes:**
- Central Processing Unit
- The "brain" of the computer that executes instructions
- more CPU cores improve multitasking
- ALU performs math and logic operations
- Control Unit directs instructuction execution
- cache stores frequently used data for faster access

**Memory/OS notes:**
- RAM is temporary (volatile) memory used by running programs
- ROM stores firmware and is non-volatile
- Cache is faster than RAM but much smaller
- Virtual memory uses disk space when RAM is full

**How this connects to security (e.g., exploitation, forensics, malware analysis):**
- Able to recognize and understand the function of various computing components

**What I struggled with:**
- Identifying the exact location for placement of the components of a CPU
